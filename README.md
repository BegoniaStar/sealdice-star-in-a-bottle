# 瓶中星光

这是给骰主“星·麒”的 SealDice 1.6.0 插件。使用 `.扔瓶子` 把内容投进星海，使用 `.捡瓶子` 随机捞取瓶子或星星；`.跳入星海` 每位用户每天可化作一颗星星。骰主可用 `.查看投放者 <瓶子 ID>` 查询历史投放者，`.查看星海` 查看当前数量，`.星海` 查看帮助。

## 使用指令

在已启用插件的群聊中，使用骰子的常规指令前缀（通常为 `.`）发送下列指令：

| 指令                    | 用途                                                                     | 示例                               |
| ----------------------- | ------------------------------------------------------------------------ | ---------------------------------- |
| `.星海`                 | 查看普通用户可用的指令帮助。                                             | `.星海`                            |
| `.扔瓶子 <内容>`        | 将一段文字放入漂流瓶并投进星海。                                         | `.扔瓶子 愿你今夜也有好梦`         |
| `.捡瓶子`               | 随机捞取星海中的一个漂流瓶或一颗星星；捞出的物品会离开星海。             | `.捡瓶子`                          |
| `.查看星海`             | 查看星海当前的瓶子与星星总数。                                           | `.查看星海`                        |
| `.跳入星海`             | 跳入星海并留下一颗随机样式的星星；每位用户每天限一次。                   | `.跳入星海`                        |
| `.查看投放者 <瓶子 ID>` | 查询指定漂流瓶的投放者 QQ 号；仅骰主可用。瓶子 ID 会随捡取结果一同显示。 | `.查看投放者 bottle_1735689600000` |

若想查看某条指令的宿主帮助，可在后面加上 `help`，例如 `.扔瓶子 help` 或 `.查看投放者 help`。

### 一个完整流程

```text
.扔瓶子 今天也要加油       # 投放内容
.查看星海                 # 确认星海数量
.捡瓶子                   # 随机捞取瓶子或星星
```

捡到漂流瓶时，回复中会显示瓶子 ID；骰主可以把这个 ID 交给 `.查看投放者` 查询投放者 QQ 号。用户使用 `.跳入星海` 后，当天再次使用会收到每日次数已用尽的提示。

## 配置

所有回复、帮助文案和星星样式均可在扩展配置中修改；文案配置支持多候选值和 SealDice 模板语法。数据使用扩展存储，键名为 `sea`、`allBottles`、`jumpRecords`。
